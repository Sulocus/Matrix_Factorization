# Spreading No-Gaussian-Posterior Ablation

![QY cosine ablation](qy_cosine_no_gaussian_posterior_ablation.png)

This folder keeps one in-process ablation for no-Onsager spreading: the
Gaussian posterior shrinkage assumption is removed while the other
configuration choices are kept fixed. The main implementation was restored
after the run.

Two figures are provided: output projection and output cosine.
