  implementation_components: |
    # 1. TENSOR RING (TR) CONTRACTION ENGINE (models/tensor_ring.py)
    - Purpose: Implements the forward model $u_x = \text{Tr}(\prod_{i=1}^d Z_i(:, x_i, :))$.
    - Technical Detail: Use `numpy.einsum` or `opt_einsum` to handle the trace of core products. For a $d$-th order tensor, the contraction follows: $u_{x_1...x_d} = \sum_{\ell_1...\ell_d} Z_1(\ell_1, x_1, \ell_2) Z_2(\ell_2, x_2, \ell_3) \dots Z_d(\ell_d, x_d, \ell_1)$.
    - Complexity: $O(d \cdot N \cdot r^3)$ where $r$ is the TR-rank.

    # 2. TeG-AMP SOLVER (solvers/teg_amp.py)
    - Purpose: Implementation of Algorithm 1 (Appendix F).
    - Step A (Forward Pass): Compute $\bar{p}_x(t)$ as the TR contraction of current means $\hat{Z}$.
    - Step B (Plug-in Variance - Eq 25): This is the most complex term.
      $\bar{\nu}_{p,x}(t) = \sum_{\ell'} \sum_{A \subsetneq D, A \neq \emptyset} (\prod_{i \in A} \hat{Z}_{i,x_i}^{\ell'}(t)^2 \prod_{i'' \in D \setminus A} \nu_{Z,i'',x_{i''}}^{\ell'}(t) - \hat{s}_x(t-1) \dots)$.
      *Implementation Note*: For $d=3$, explicitly expand the subsets $A$ to avoid recursive overhead.
    - Step C (Residuals - Eq 17, 18):
      $\hat{s}_x = (\hat{u}_x - \hat{p}_x) / \nu^p_x$
      $\nu^s_x = (1 - \nu^u_x / \nu^p_x) / \nu^p_x$
    - Step D (Backward Pass - Eq 27, 28): Update the "latent observations" $\hat{r}_{qi}$ and variances $\nu^r_{qi}$ for each core $Z_i$. This requires calculating the partial contraction of all cores *except* $i$.

    # 3. TeS-AMP SOLVER (solvers/tes_amp.py)
    - Purpose: Implementation of Algorithm 2 (Appendix H.5) for CP-rank tensors.
    - Optimization: Replaces the TR trace with a simple summation over $r$ components. The variance update $\nu^q_{p,x}$ is exact here, simplifying the subset summation logic of TeG-AMP.

    # 4. ADAPTIVE DAMPING CONTROLLER (utils/damping.py)
    - Purpose: Ensure convergence in finite-dimensional settings (Appendix G).
    - Logic: Implement the cost criterion $J(t) = \sum \text{KL}(q \| p) - \sum \mathbb{E}[\log p(v|u)]$.
    - Update Rule: If $J(t) > J(t-1)$, reject the step, set $\beta = \beta \cdot 0.5$, and re-run iteration $t$. If $J(t) \leq J(t-1)$, accept and set $\beta = \min(1, \beta \cdot 1.1)$.
    - Variables to Damp: $\hat{s}_x$, $\nu^s_x$, $\hat{Z}_{i,x_i}$, and $\nu^Z_{i,x_i}$.

    # 5. PRIORS AND CHANNELS (utils/priors.py, utils/channels.py)
    - Gaussian Prior: $\hat{Z} = \hat{r} / (1 + \nu^r)$, $\nu^Z = \nu^r / (1 + \nu^r)$.
    - AWGN Channel (Completion): 
      For $x \in \Omega$: $\hat{u}_x = (v_x \nu^p_x + \hat{p}_x \nu^w) / (\nu^p_x + \nu^w)$.
      For $x \notin \Omega$: $\hat{u}_x = \hat{p}_x$, $\nu^u_x = \nu^p_x$.
    - Noise Variance Estimation ($\nu^w$): Implement Eq 165 to adaptively estimate noise levels if not provided.
