# Archived Trials

share cleanup. They remain registered with `status: archived` so previous
calibration and diagnostic configs are still discoverable, but they are no
longer part of the active trial surface.

The active trial surface is intentionally small:

- quick contract/smoke trials used by tests;
- the three `qy_compare_200_m50_*` configs used for the current main showcase.
