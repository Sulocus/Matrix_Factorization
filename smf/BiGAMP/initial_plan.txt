  # SECTION 2: Implementation Components
  implementation_components: |
    The reproduction requires four primary technical modules integrated into a single execution flow.

    1. THE BiG-AMP ENGINE (core/engine.py)
    Implement the Scalar Variance BiG-AMP (Table IV) for computational efficiency O(N|Ω|).
    - Input: Observation matrix Y, sampling mask Ω, and Estimator objects for A, X, and Z.
    - State Initialization: 
      * a_hat, x_hat: Random Gaussian or zeros.
      * νa, νx: Set to 10x the expected prior variance to allow initial data dominance.
      * s_hat: Initialize to zeros (size M x L).
    - The 16-Step Loop (Iterative):
      * R1-R4 (Z-updates): Compute p_hat using Onsager correction: p_hat = (A_hat * X_hat) - (s_hat_prev * νp).
      * R5-R8 (Residual updates): Call Z-Estimator (Likelihood) to get posterior mean z_hat and variance νz. Compute residual s_hat = (z_hat - p_hat) / νp_bar.
      * R9-R12 (R/Q-updates): Compute effective noise-corrupted observations for X (r_hat) and A (q_hat).
      * R13-R16 (A/X-updates): Call A and X Estimators (Priors) to get updated a_hat, x_hat and their variances.

    2. NON-LINEAR ESTIMATORS (estimators/)
    Each estimator must implement `estimate(mean_in, var_in)` returning `(mean_out, var_out)`.
    - Gaussian Estimator: 
      * mean_out = (mean_in * ν_prior) / (ν_prior + var_in)
      * var_out = (ν_prior * var_in) / (ν_prior + var_in)
    - Bernoulli-Gaussian (BG) Estimator:
      * Used for sparsity. Requires calculating the posterior activity probability π_hat.
      * Formula: π_hat = [1 + ((1-λ)/λ) * (N(0; mean_in, ν_prior + var_in) / N(mean_in; 0, var_in))]^-1.
      * mean_out = π_hat * [ (mean_in * ν_prior) / (ν_prior + var_in) ].
    - PIAWGN Likelihood:
      * For (m,l) ∈ Ω: Use AWGN estimator (z_hat = (y*νp + p_hat*νw)/(νp + νw)).
      * For (m,l) ∉ Ω: Pass through (z_hat = p_hat, νz = νp).

    3. ADAPTIVE DAMPING & COST (core/damping.py)
    To prevent divergence, implement the Bethe Free Energy approximation J(t).
    - J(t) = Σ D_KL(p_post || p_prior) - E_z[log p(y|z)].
    - For AWGN, J(t) simplifies to a quadratic penalty on (z_hat - p_hat) and log-variance terms.
    - Logic: If J(t) > J_threshold, reject the step, decrease step size β (e.g., β = β * 0.5), and recompute. If J(t) improves, increase β (e.g., β = min(β * 1.1, 1.0)).

    4. EM HYPERPARAMETER TUNING (utils/em_tuner.py)
    Update parameters θ after every K BiG-AMP iterations (or upon convergence).
    - Noise Variance (νw): νw = (1/|Ω|) * Σ [(y - z_hat)^2 + νz].
    - Prior Variances (νa, νx): νx = (1/NL) * Σ [x_hat^2 + νx].
    - Sparsity Rate (λ): λ = (1/NL) * Σ [π_hat].

    5. RANK SELECTION (utils/rank_logic.py)
    - Rank Contraction: Start with a large N. After initial EM iterations, perform SVD on X_hat. If singular values drop below a threshold, reduce N and truncate matrices.
    - AICc: Compute the corrected Akaike Information Criterion to compare models with different inner dimensions N.
